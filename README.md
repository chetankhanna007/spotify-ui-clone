# Spotify UI Clone 🎵

A front-end **Spotify UI clone** built with HTML5 and CSS3, replicating the Spotify web player's layout and visual design.

## 🛠️ Tech Stack
- HTML5 (semantic structure)
- CSS3 (Flexbox, Grid, animations)
- Font Awesome Icons

## 🎯 Features
- Spotify-style sidebar navigation
- Music player bottom bar UI
- Album/playlist cards grid layout
- Dark theme with Spotify's green color palette
- Responsive layout
